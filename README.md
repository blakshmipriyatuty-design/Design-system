# BloomSpace – Daily Habits App

## Project Overview
BloomSpace is a personal growth and daily habit-tracking mobile app designed to help users build healthy routines, stay organized, and achieve their daily goals. It provides a simple and user-friendly experience to track habits, monitor progress, and maintain consistency.

## Objectives
- Help users develop positive daily habits.
- Make habit tracking simple and organized.
- Motivate users to achieve their personal goals.
- Track daily and weekly progress.
- Encourage consistency through progress tracking and streaks.

## Design Highlights
- Clean and minimal user interface.
- Soft mint green and warm cream colour palette.
- Modern and readable typography.
- Rounded cards and reusable UI components.
- Simple icons and clear navigation.
- Consistent spacing and accessible form elements.

## Key Features
- **Home:** View daily goals and habit summaries.
- **My Habits:** Add, manage, and complete daily habits.
- **Progress:** Track weekly achievements and completed habits.
- **Streak Tracker:** Monitor consistency over time.
- **Personal Goals:** Set goals and stay motivated.
